## 简介

该仓库包含 [nestjs.com](https://nestjs.com) 源代码，即 Nest 官方网站。

## 开发

访问 `http://localhost:1234/`。

```
$ npm install
$ npm run start
```

## 构建

运行 `npm run build` 来构建项目。构建产物将存储在 `dist/` 目录中。
